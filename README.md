# Encore React

A responsive artist discovery and booking enquiry demo built with React and Vite, featuring South African DJs, singers, bands and musicians.

## Stack
- React and Vite
- Lucide React icons
- Responsive custom CSS
- GitHub Actions and GitHub Pages

## Run locally
Install Node.js, then run:

    npm install
    npm run dev

Create a production build with npm run build.

## Features
- Artist cards with genre, city, reviews and indicative event pricing
- Search by artist, genre or city
- Category and city filters
- Saved favourites using local storage
- Booking enquiry form with validation
- Responsive desktop and mobile layouts
- Automated GitHub Pages deployment on pushes to main

## Demo limitations
Profiles and pricing are sample data. Booking enquiries open a prepared email draft and are not stored or sent to a live booking service. There are no live artist accounts, payments or backend yet.
